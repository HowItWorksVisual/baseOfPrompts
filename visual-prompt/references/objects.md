# Идея → предмет

Предмет должен работать так же, как идея: его движение и есть объяснение. Ниже — занятые в базе и свободные пары.

## Уже в базе

| Идея | Предмет | Запись |
|---|---|---|
| Усиление малого перемещения | Индикатор часового типа над мерными блоками | dial-indicator |
| Ввод → вывод, гашение ЭЛТ | Настольный компьютер 1984 | desk-computer |
| Событие будит систему | Аркадный автомат и монета | arcade-cabinet |
| Ступенчатое сгорание | Raptor 2 на стенде | raptor-engine |
| Интерференция | Волновая ванна | ripple-tank |
| Комбинация, 3D-поворот | Кодовый диск и рука робота | turning-dial |
| Token bucket | Бункер-дозатор жетонов | token-bucket |
| Пул соединений | Ручной телефонный коммутатор | connection-pool |
| Гистерезис | Котёл и биметаллический термостат | thermostat-boiler |
| Leaky bucket | Клепсидра | leaky-bucket |
| Кэш на краю CDN, TTL | Стеллаж ячеек с песочными часами + пневмопочта | cdn-edge-cache |
| Ключ кэша, мемоизация | Цилиндровый замок | cache-key-lock |
| Размеры типов | Комод с ящиками глубиной в байты | memory-drawers |
| Раздельная свёртка | Штамп-гвоздильня против двух гребёнок | separable-blur |
| Round-robin | Распределитель зажигания | round-robin-distributor |

## Свободные идеи

| Идея | Предмет |
|---|---|
| Общий GPU-контекст на много холстов | Портальный плоттер: одна головка обходит 16 лунок |
| Профиль высот | Контурный шаблон (гребёнка), прижатый к кромке |
| Освещение и нормали | Фотостудия: рисующий и заполняющий свет вокруг поворотного стола |
| Пружина: давит и наклоняется | Испытательный стенд с пружинами, щупом и индикатором |
| Двоичный поиск | Аптекарские весы и набор гирь, делящий диапазон пополам |
| Хэш-таблица и коллизии | Почтовый сортировщик с ячейками и цепочками конвертов |
| Очередь сообщений / pub-sub | Пневмопочта с распределительной станцией |
| Сборка мусора (mark & sweep) | Сортировочный конвейер с метками и сбросом |
| Git-ветки и слияние | Железнодорожный стрелочный перевод с разъездами |
| Circuit breaker | Автоматический выключатель на DIN-рейке с биметаллом |
| Debounce / throttle | Дверной доводчик с масляным демпфером |
| TCP-окно перегрузки | Шлюз на канале с регулируемыми воротами |
| Шардирование | Картотека с ящиками по алфавиту |
| Бэкпрешер | Гидравлический пресс с перепускным клапаном |

Перед использованием перенеси пару в «Уже в базе».
