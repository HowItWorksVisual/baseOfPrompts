# Форматы

Все три — режимы вывода одного и того же skill anatomy. Строку вывода копировать в промт дословно.

## svg — статичный .svg

Когда: иллюстрация для статьи, лендинга, README; движение не нужно, важен один выразительный момент.

```
Вывод: один отдельный .svg-файл со встроенными стилями (figureSvg({ standalone })), тема {theme}, плюс PNG-превью.
```

В «Что движется» описывай застывший момент: какое состояние показано и где видно контраст (попадание против промаха, два замка рядом и т.п.). `animated: false`.

## html — живая фигура

Когда: интерактивный explainer — читатель двигает, нажимает, печатает, и фигура отвечает.

```
Вывод: один standalone HTML-файл (framework-free, сборка через build.mjs), который открывается двойным кликом, тема {theme}.
```

Опиши управление: указатель, клавиши, тур без касаний, reduced motion. Для React/Next.js можно заменить строку на «React-компонент (TSX) + standalone HTML-превью».

## webgl — шейдеры или 3D

Когда: то, что не нарисовать линиями — огонь и выхлоп, вода и каустики, свет лампы, свечение, пар; или деталь, которая по-настоящему поворачивается в 3D.

```
Вывод: один standalone HTML-файл (framework-free) со слоями SVG + WebGL внутри рисунка, тема {theme}. Без WebGL фигура должна читаться как обычный SVG.
```

Назови, какой эффект на WebGL и к какой плоскости он привязан (пол, стенка, сосуд). Для 3D-режима добавь «в 3D-режиме (beta)» и что именно вращается. Несколько WebGL-слоёв или 3D — это обычно размер Hero.

## Размеры

| Размер | Деталей | Время у anatomy | Когда |
|---|---|---|---|
| Figure | 40–80 | до часа | одна идея, один механизм — по умолчанию |
| Hero | 80–150 | 2–4 часа | плотный объект, разрез, несколько WebGL-слоёв, 3D |
